My work spans Python and JavaScript automation, payment-enabled APIs, MCP integrations, security tooling, data pipelines, web applications, and trading-platform utilities.

## Featured work

### [DopamineDesk x402 Marketplace](https://github.com/jblaz6335/mcp-server-aidatamarketplace)

A production MCP server and machine-to-machine data marketplace using the x402 payment protocol on Base Mainnet.

- Pay-per-request USDC payments with no subscriptions or API keys
- Live data products for EVM, markets, compliance, business identity, and public commerce
- Published through npm, the official MCP Registry, Smithery, and x402scan
- Bounded live previews, payment safety limits, OpenAPI documentation, and automated verification

### [AI Data Marketplace API](https://github.com/jblaz6335/ai-data-marketplace-api)

The public OpenAPI contract for a decentralized data marketplace built for agents and automated clients.

- Machine-readable API discovery
- x402 payment metadata
- Base Network USDC settlement model
- Designed for MCP and autonomous software integrations

### [Glitch Garage](https://github.com/jblaz6335/glitch-garage)

A full-stack vehicle build planner that generates budget, mid-range, and full-send project plans.

- React and Vite progressive web application
- Node.js and Express backend
- SQLite persistence, JWT authentication, and rate limiting
- Location-based salvage-yard discovery
